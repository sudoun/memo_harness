# Security policy

## Supported versions

Security fixes are made for the latest released version of
`posterior-memory-harness`. At present, that is the 0.9.x line.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability and do not include
credentials, private datasets, or a working exploit in public content.

Use GitHub's private vulnerability-report flow for this repository:

<https://github.com/sudoun/memo_harness/security/advisories/new>

If that private-reporting page is unavailable, open a minimal public issue
requesting a private reporting channel without describing the vulnerability.
